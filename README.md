# Коворк

Интерактивный прототип рабочего пространства для городских данных, проектов и аналитики. Интерфейс основан на макетах Figma; используются локальные демонстрационные данные.

## Запуск

Node.js 22 и npm.

```sh
npm ci
npm run dev
```

```sh
npm run lint
npm run typecheck
npm run build
npm run preview
```

## Сценарии

- Первый вход → приветственный экран → выбор роли и задач → главная. После завершения знакомства повторный вход открывает рабочее пространство.
- Главная → вопрос ассистенту → этапы обработки → карта, график и выводы.
- Дашборды → описание задачи → аудитория → оформление → источники → план → генерация → редактор → локальная публикация.
- Проекты → создание → обзор → чаты, источники, документы, автоматизации, решения, задачи, пакеты, настройки.
- Задачи → список или канбан → создание, изменение статуса и сохранение.
- Интеграции → подключение и отключение демоисточников.
- Автоматизации → схема React Flow → расписание, источники, условия и действия → настройка узлов и соединений → демонстрационный запуск и журнал. Схемы можно создавать, перемещать, соединять, сохранять и выгружать в JSON.
- Профиль → онбординг, настройки, помощь и сброс демонстрации.

Изменения сохраняются в localStorage текущего браузера. Публикация дашбордов локальная: ссылка открывает страницу прототипа; созданные данные не передаются другим посетителям. Настоящие ИИ, серверные интеграции, совместная работа и отправка приглашений не подключены. Голосовой ввод использует подготовленную фразу. Документы открывают демонстрационное содержимое; выгрузки имеют соответствующие текстовые форматы.

## Структура

- `src/App.tsx` — оболочка, навигация, маршруты.
- `src/demo.ts` — общие сущности и сохраняемое состояние.
- `src/ui.tsx`, `src/coss` — общие компоненты и переиспользованная база Base UI.
- `src/features/HomeChat.tsx` — главная, чат и онбординг.
- `src/features/Dashboards.tsx`, `Chart.tsx` — мастер, редактор и ECharts.
- `src/features/Projects.tsx` — проекты и рабочие вкладки.
- `src/features/Automations.tsx` — нодовые автоматизации на React Flow; механизмы узлов и связей адаптированы из предоставленного ECP3 без переноса MUI.
- `src/Utilities.tsx` — интеграции, профиль и помощь.
- `public/assets` — локальные изображения из макетов, шрифт и лицензия шрифта.

Хеш-маршрутизация поддерживает прямые ссылки и перезагрузку на GitHub Pages. Workflow `.github/workflows/deploy.yml` проверяет и публикует ветку `main`. Для другой подпапки хостинга задайте `VITE_BASE_PATH` при сборке.

## Источники интерфейса

[Макеты Figma](https://www.figma.com/design/SvXyDZnbpUbzjik5lp7Xen/?node-id=12157-8517). Часть базовых компонентов переиспользована из предоставленного проекта `azs-frontend`. Шрифт Golos Text распространяется по OFL; текст лицензии находится в `public/assets/GolosText-OFL.txt`.
